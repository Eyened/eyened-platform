# EyeNED

EyeNED stores, views and grades retinal images for research projects, with access limited to each project's members.

## Language

**External data source**:
A named service outside EyeNED that a site configures to hold extra data about a study, shown alongside that study to users who can see it.
_Avoid_: Extension, data source plugin, Optio (the name of one site's source)

**Source format**:
The agreed shape of the data an external data source returns; the first and default format is **named tables**: titled tables of plain rows.
_Avoid_: schema, payload type
