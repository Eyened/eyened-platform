The **Rendering** panel controls how the current image is displayed on the canvas — window/level, stretch, and enhancement modes (CLAHE, contrast, color channels, etc.). Changes are **view-only**; they do not modify stored pixels or annotations.

## Using the panel

### Typical controls

- **Window / level** — adjust brightness and contrast for grayscale and OCT
- **Stretch** — fit the intensity range to the viewport
- **Render mode** — original, CLAHE, sharpened, single color channel, and other presets (modality-dependent)

Rendering controls may also appear as overlays on the main canvas for some modalities. Adjust settings until structures you need to annotate are clearly visible, then switch to annotation panels.
