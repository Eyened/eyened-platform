The Eyened ORM is a Python library (SQLAlchemy 2.0) for direct database access — queries, bulk updates, imports, and model inference. **Start here** before using the [importer](/eyened-platform/orm/importer), [DICOM export](/eyened-platform/orm/dicom_export), [CLI](/eyened-platform/orm/cli), or notebooks.

## When to use the ORM vs the API

| Use the ORM | Use the [API](/eyened-platform/api) |
|-------------|-------------------------------------|
| Bulk operations and custom pipelines | Standard CRUD from applications |
| Import, dumps, inference CLI | Built-in validation and HTTP integration |
| Fields or relationships not exposed by the API | Web-facing integrations |

:::note
The ORM gives broad, low-level access. Skim the [data model](/eyened-platform/orm/data_model) before changing production data.
:::

## Install

```bash
git clone https://github.com/Eyened/eyened-platform.git
cd eyened-platform/orm
pip install -e .
```

Verify the CLI:

```bash
eorm --help
```

## Configure environment

The ORM reads **`EYENED_DATABASE_*`** variables (and optionally **`EYENED_STORAGE_*`**, **`EYENED_API_*`**) from the environment or a `.env` file.

Minimum for database access:

```bash
EYENED_DATABASE_HOST=localhost
EYENED_DATABASE_PORT=3306
EYENED_DATABASE_USER=eyened
EYENED_DATABASE_PASSWORD=...
EYENED_DATABASE_DATABASE=eyened_database
```

For local file access (thumbnails, segmentations, import preparation):

```bash
EYENED_STORAGE_ROOT=/storage
EYENED_STORAGE_MOUNTS='{"local":"/path/to/images"}'
```

Full variable list: **[Configuration](/eyened-platform/orm/configuration)**.

Point the CLI at a specific env file:

```bash
eorm -e /path/to/.env create-user
```

## Connect from Python

```python
from dotenv import load_dotenv
from eyened_orm import Database

load_dotenv("/path/to/.env")  # optional if vars are already in the environment
db = Database()

with db.get_session() as session:
    # queries, imports, etc.
    ...
```

Prefer `get_session()` for automatic cleanup; use `create_session()` only when you manage the lifecycle yourself.

## Quick query example

```python
from sqlalchemy import select
from eyened_orm import Project, Patient

project = Project.by_name(session, "My Project")
patients = session.scalars(
    select(Patient).where(Patient.ProjectID == project.ProjectID)
).all()
```

ORM properties support SQL column names (`PatientIdentifier`) and snake_case (`patient_identifier`).
