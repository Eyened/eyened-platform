The `eorm` CLI covers database setup, maintenance, and inference entry points. Use `eorm --help` and `eorm COMMAND --help` for current flags.

:::note
**Inference commands** (`run-cfi-models`, `run-segmentation`, `run-registration`, …) are summarized in **[Inference](/eyened-platform/orm/inference)**. **Thumbnails**: **[Thumbnails](/eyened-platform/thumbnails)**.
:::

## Database setup

### initialize-database

Creates tables on an empty database and stamps the current Alembic revision.

```bash
eorm initialize-database [--seed-form-schemas] [--recreate]
```

### seed-form-schemas

Inserts builtin viewer FormSchemas (ETDRS, registration). See **[Form schemas](/eyened-platform/orm/form_schemas)**; registration semantics: **[Registration](/eyened-platform/orm/registration)**.

```bash
eorm seed-form-schemas [--update]
```

### create-user

Interactive user creation for viewer/API login.

```bash
eorm create-user
```

## Inference (summary)

| Command | Purpose |
|---------|---------|
| `run-cfi-models` | CFI attribute inference (`cfi-roi`, `cfi-keypoints`, `cfi-odfd`, `cfi-quality`) |
| `run-models` | Deprecated alias for `run-cfi-models` |
| `run-segmentation` | Segmentation model inference |
| `run-registration` | Enface image registration — see **[Registration](/eyened-platform/orm/registration)** |
| `run-etdrs-model` | ETDRS subfield areas |

`run-cfi-models` flags include `--overwrite` (reprocess current version), `--upgrade` (add current version output when only older versions exist), and `--failed` (retry failed rows within the target). Attribute read precedence: **[Attributes](/eyened-platform/orm/data_model/attributes#selecting-which-attributevalue-to-use)**.

Details: **[Inference](/eyened-platform/orm/inference)**.

## Targeting

Image- and patient-scoped commands share targeting flags. For most inference commands, provide **at least one** of:

| Flag | Description |
|------|-------------|
| `-p` / `--path` | File with one `ImageInstanceID` or `PublicID` per line |
| `--image-ids` | Comma-separated IDs or PublicIDs |
| `--project` | Project ID or name |
| `--patient` | Patient identifier (with `--project` if ambiguous) |
| `--exclude` / `--skip` | IDs or PublicIDs to exclude |
| `--modality` | Filter by modality (also when targeting all images) |

```bash
eorm run-cfi-models --project "AMD-Study" --modality ColorFundus
eorm update-thumbnails --path ids.txt
```

`run-cfi-models`, `update-thumbnails`, and `update-hashes` scan the whole database when no target flags are given.

## Maintenance

### update-thumbnails

Backfill missing `ThumbnailPath` values. See **[Thumbnails — CLI](/eyened-platform/thumbnails#cli)**.

### update-hashes

Fill missing `FileChecksum` and `DataHash` on image instances.

### validate-forms

Validate `FormAnnotation` JSON against schemas.

### zarr-tree / defragment-zarr

Inspect or compact `{EYENED_STORAGE_ROOT}/segmentations.zarr`.

## Database dumps

### load-dump / save-dump

Load or create SQL dumps. **`load-dump` is destructive** — drops and recreates the target database.

```bash
eorm save-dump -p /path/to/dump_dir
eorm load-dump -p /path/to/dump.sql
```
