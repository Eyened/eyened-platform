This document lists API routes mounted under `/api`. All routes require authentication unless noted otherwise.

**Authentication:** web clients use session cookies after `POST /api/auth/login`; API clients use `Authorization: Bearer <token>` from `POST /api/auth/token` or login with `"api_client": true`.

**Image identifiers:** most user-facing routes use **`PublicID`** (12-character string). `GET /api/instances/{instance_id}` uses the numeric **`ImageInstanceID`**. Some routes accept either public ID or numeric ID as a fallback.

**Health check (no auth):** `GET /health` — outside `/api`.

## Authentication

### POST /api/auth/login

Login with username and password.

**Request body:**
```json
{
  "username": "string",
  "password": "string",
  "api_client": false
}
```

- `api_client: false` (default) — sets JWT cookies; returns user info.
- `api_client: true` — returns `access_token`, `refresh_token`, and user info in the JSON body (no cookies).

### POST /api/auth/token

Get a Bearer access token for API clients (no refresh token in response).

**Request body:** `{ "username": "string", "password": "string" }`

### GET /api/auth/me

Current authenticated user (id, username, role, starred tags).

### POST /api/auth/change-password

**Request body:** `{ "old_password": "string", "new_password": "string" }`

### POST /api/auth/register

Register a new user (may require admin privileges depending on deployment).

### POST /api/auth/refresh

Refresh the access-token cookie using the **refresh-token cookie** (web clients only; no request body).

### POST /api/auth/logout

Clear JWT cookies.

## Image instances

### GET /api/instances/\{instance_id\}

Get one image by numeric **`ImageInstanceID`**.

**Query parameters:** `with_segmentations`, `with_form_annotations`, `with_model_segmentations`, `with_tag_metadata` (all bool, default `false`).

### GET /api/images/\{image_id\}

Get one image by **`PublicID`** (preferred). If `image_id` is all digits, falls back to numeric `ImageInstanceID`.

Same query parameters as `GET /api/instances/{instance_id}`.

### GET /api/images/\{image_id\}/data

Image file via nginx `X-Accel-Redirect`.

**Query parameters:** `index` (int, volume slice), `meta` (bool, sidecar metadata for some formats).

### GET /api/images/\{image_id\}/thumbnail

Thumbnail via nginx redirect.

**Query parameters:** `size` (int, default `144`) — `144` or `540`.

### GET /api/instances/images/\{dataset_identifier:path\}

**Legacy.** Serve image by deprecated `DatasetIdentifier` path (`/files/…` redirect).

### GET /api/instances/thumbnails/\{thumbnail_identifier:path\}

**Legacy.** Serve thumbnail by path under `thumbnails/` (typically `{ThumbnailPath}_{size}.jpg`). Prefer `GET /api/images/{image_id}/thumbnail`.

### POST /api/instances/\{instance_id\}/tags

Attach a tag to an image. **`instance_id` is the image `PublicID`**.

**Request body:** `{ "tag_id": int, "comment": "string" | null }`

### PATCH /api/instances/\{instance_id\}/tags/\{tag_id\}

Update tag comment on an image (`PublicID`).

**Request body:** `{ "comment": "string" | null }`

### DELETE /api/instances/\{instance_id\}/tags/\{tag_id\}

Remove tag from an image (`PublicID`).

## Import

See also [Importing data](/eyened-platform/importing_data) and [Thumbnails](/eyened-platform/thumbnails).

### POST /api/import/image

Import a single flat `ImportRow`.

**Request body:** `{ "data": { …ImportRow… }, "options": { "include_stack_trace": false } }`

### POST /api/import/update_thumbnails

Queue thumbnail generation for all images with missing (or optionally failed) `ThumbnailPath`.

**Query parameters:** `failed` (bool), `print_errors` (bool)

**Response:** `TaskResponse` — `{ "success", "message", "task_id", "task_ids", "error" }`

### POST /api/import/update_thumbnails_for_image_ids

**Request body:** `{ "image_ids": [int, …], "print_errors": bool }`

### GET /api/import/status/\{task_id\}

Poll RQ job status. **No authentication required.**

**Response:** `{ "task_id", "status", "result" }` or `{ "error": "job not found" }`

### POST /api/import/run_cfi_models

Queue CFI attribute models (`cfi-roi`, `cfi-keypoints`, `cfi-odfd`, `cfi-quality`).

**Request body:**
```json
{
  "image_ids": [1, 2],
  "model": "cfi-roi",
  "overwrite": false,
  "commit_interval": 100,
  "batch_size": 8,
  "n_workers": 16
}
```

Omit `model` to queue one job per attribute model. **Response:** `task_id` (first job) and `task_ids` (all jobs).

### POST /api/import/run_cfi_amd

Queue CFI AMD segmentation (`cfi-amd` queue).

**Request body:** `{ "image_ids": [int, …], "overwrite": bool, "batch_size": 8, "n_workers": 12 }`

### POST /api/import/run_layer_segmentation

Queue OCT layer segmentation (`layer-segmentation` queue).

**Request body:** `{ "image_ids": [int, …], "overwrite": bool }`

## Segmentations

### POST /api/segmentations

Create a segmentation. **`image_id` is the image `PublicID`.**

**Request body:** dimensions, `data_type`, `data_representation`, `feature_id`, optional `subtask_id`, etc.

### GET /api/segmentations/\{segmentation_id\}

Get segmentation metadata.

### PATCH /api/segmentations/\{segmentation_id\}

Update metadata (`feature_id`, `threshold`, `reference_segmentation_id`, …).

### DELETE /api/segmentations/\{segmentation_id\}

Delete segmentation.

### PUT /api/segmentations/\{segmentation_id\}/data

Upload segmentation voxel data.

**Body:** `Content-Type: application/octet-stream` — NumPy array bytes (`np.save` format).

**Query parameters:** `axis`, `scan_nr` (optional slice indexing).

### GET /api/segmentations/\{segmentation_id\}/data

Download segmentation data as **gzip-compressed NumPy** (`application/octet-stream`).

**Query parameters:** `axis`, `scan_nr`

### POST /api/segmentations/\{segmentation_id\}/tags

Add tag to segmentation.

### DELETE /api/segmentations/\{segmentation_id\}/tags/\{tag_id\}

Remove tag from segmentation.

### GET /api/model-segmentations/\{model_segmentation_id\}/data

Download model segmentation data (gzip NumPy). Query: `axis`, `scan_nr`.

### PUT /api/model-segmentations/\{model_segmentation_id\}/data

Upload model segmentation data (`application/octet-stream` NumPy). Query: `axis`, `scan_nr`.

## Tasks

**Request body:** `{ "name", "description", "contact_id", "task_definition_id" }`

### GET /api/task/\{task_id\}

### DELETE /api/task/\{task_id\}

### GET /api/task/\{task_id\}/subtasks

List subtasks with optional pagination and images.
