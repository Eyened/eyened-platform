All routes are under `/api` and require authentication unless noted. Prefer topic pages for context; this page is a quick lookup.

**Overview:** **[API overview](/eyened-platform/api)** · **PublicID** for most image routes · **`GET /health`** (no auth, outside `/api`).

| Route | Topic page |
|-------|------------|
| `POST /api/auth/login`, `/token`, `/me`, `/logout`, … | [Authentication](/eyened-platform/api/authentication) |
| `GET /api/images/{id}`, `/data`, `/thumbnail`, … | [Images & patients](/eyened-platform/api/images) |
| `GET /api/patients/{id}` | [Images & patients](/eyened-platform/api/images) |
| `POST /api/import/*` | [Import](/eyened-platform/api/import) |
| `GET /api/import/status/{task_id}` | [Import](/eyened-platform/api/import) (no auth) |
| `/api/segmentations/*`, `/api/model-segmentations/*` | [Segmentations](/eyened-platform/api/segmentations) |
| `/api/features/*` | [Features](/eyened-platform/api/features) |
| `/api/form-annotations/*`, `/api/form-schemas/*` | [Forms](/eyened-platform/api/forms) |
| `/api/task/*`, `/api/subtasks/*` | [Tasks](/eyened-platform/api/tasks) |
| `/api/tags/*`, `/api/studies/{id}/tags` | [Tags](/eyened-platform/api/tags) |
| `/api/instances/search`, `/api/studies/search` | [Search](/eyened-platform/api/search) |
| `GET /api/devices` | [Devices](/eyened-platform/api/devices) |

For request/response shapes, see the topic pages above or `client/src/types/openapi.json` in the repository.
