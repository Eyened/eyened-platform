## Tags

### GET /api/tags

List all tags (no filters).

### POST /api/tags

**Request body:** `{ "name": "string", "tag_type": "ImageInstance", "description": "string" }`

`tag_type`: `Study`, `ImageInstance`, `Segmentation`, `FormAnnotation`, …

### PATCH /api/tags/\{tag_id\}

### DELETE /api/tags/\{tag_id\}

### POST /api/tags/\{tag_id\}/star

Star tag for current user.

### DELETE /api/tags/\{tag_id\}/star

Unstar tag.
