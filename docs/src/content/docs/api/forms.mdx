## Form annotations

### GET /api/form-annotations

**Query parameters:** `patient_id`, `study_id`, `image_id` (`PublicID`), `form_schema_id`, `sub_task_id` (all optional filters).

### POST /api/form-annotations

**Request body:**
```json
{
  "form_schema_id": 1,
  "patient_id": 1,
  "study_id": 1,
  "image_id": "abc123public",
  "laterality": "R",
  "sub_task_id": 1,
  "form_data": {},
  "form_annotation_reference_id": null
}
```

`image_id` is **`PublicID`**, not numeric ID.
