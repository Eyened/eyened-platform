The API **registers** images that already exist on a storage backend — it does not upload file bytes. See **[Importing data](/eyened-platform/importing_data)**.

::::note
`POST /api/import/image` does **not** run DICOM header preparation (`infer_metadata_from_dicom_header` / `link_oct_enface_series`). Supply PatientID, study date, modality, and series linking on the row yourself, or use the [ORM importer](/eyened-platform/orm/importer#row-preparation) with `PreparationOptions`.
::::

### POST /api/import/image

Import a single flat `ImportRow`.

**Request body:** `{ "data": { …ImportRow… }, "options": { "include_stack_trace": false } }`

Field reference: **[Import metadata fields](/eyened-platform/import_metadata_fields)**.

### POST /api/import/update_thumbnails

Queue thumbnail generation for all images with missing (or optionally failed) `ThumbnailPath`.

**Query parameters:** `failed` (bool), `print_errors` (bool)

**Response:** `TaskResponse` — `{ "success", "message", "task_id", "task_ids", "error" }`

See **[Thumbnails](/eyened-platform/thumbnails)**.

### POST /api/import/update_thumbnails_for_image_ids

**Request body:** `{ "image_ids": [int, …], "print_errors": bool }`

### GET /api/import/status/\{task_id\}

Poll RQ job status. **Authenticated**, but not scoped to project memberships — the response carries no project data. Job ids are `uuid4` and are not enumerable here.

**Response:** `{ "task_id", "status", "result" }` or `{ "error": "job not found" }`

### POST /api/import/run_model

Queue registered models (`cfi-roi`, `cfi-keypoints`, `cfi-odfd`, `cfi-quality`, `cfi-amd`, `cfi-drusen`, `layer-segmentation`). Requires the grader role on every image. One job per model goes to the RQ queue named after the model; each job only processes the image modalities that model supports. See **[Inference — workers](/eyened-platform/orm/inference#workers-and-images)**.

**Request body:**
```json
{
  "image_ids": [1, 2],
  "models": ["cfi-roi", "cfi-keypoints"],
  "mode": "default",
  "upscale": false,
  "batch_size": null,
  "n_workers": null,
  "commit_interval": null
}
```

Omit `models` to queue every model in registry order. `mode` is one of `default`, `upgrade`, `failed` or `overwrite` (see **[skip and re-run behaviour](/eyened-platform/orm/inference#skip-and-re-run-behaviour)**); `failed` jobs for segmentation models fail. `null` tuning fields use the model's defaults.

**Response:** `TaskResponse` with one id per queued model in `task_ids`.

CLI equivalents: **[Inference](/eyened-platform/orm/inference)**.
