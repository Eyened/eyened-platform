The FastAPI server exposes JSON endpoints under **`/api`**. Almost all routes require authentication.

## Authentication

| Client type | How to authenticate |
|-------------|---------------------|
| **Web viewer** | Session cookies after `POST /api/auth/login` |
| **Scripts / integrations** | `Authorization: Bearer <token>` from `POST /api/auth/token` or login with `"api_client": true` |

Details: **[Authentication](/eyened-platform/api/authentication)**. Platform setup: **[Guides — Authentication](/eyened-platform/guides/authentication)**.

**Health check (no auth):** `GET /health` — outside `/api`.

## Identifiers

| ID type | Used for |
|---------|----------|
| **`PublicID`** (12-char string) | Preferred in user-facing routes — images, tags, subtask image links |
| **`ImageInstanceID`** (integer) | `GET /api/instances/{id}`; some routes accept numeric strings as fallback |
