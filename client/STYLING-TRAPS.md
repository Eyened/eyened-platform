# Styling traps

Facts about Tailwind 4, bits-ui and jsdom that cost time once. Carbon rules themselves are in `DESIGN.md`.

## Traps

| Trap                                                                                                                                                                | What to do                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An unknown class (`bg-primary`, `text-sm`, `p-[13px]`) generates no CSS and no error                                                                                | Only the token check catches it                                                                                                                                                                                                                                                   |
| tailwind-merge reads `text-<carbon type token>` as a colour and drops it when a colour class follows                                                                | Use `cn` from `$lib/utils` and the configured `tv`; a new or regenerated `tv()` file imports the configured one                                                                                                                                                                   |
| Tailwind emits only theme variables a class references                                                                                                              | Write class names in full (`"text-status-gray"`), never `` `text-status-${x}` ``                                                                                                                                                                                                  |
| `--spacing` must stay: `tw-animate-css` and `calendar.svelte` call `--spacing()`                                                                                    | Use only Carbon's steps: `0.5 1 2 3 4 6 8 10 12 16 20 24 40`                                                                                                                                                                                                                      |
| A bare `border` draws in `currentColor` (Tailwind v4), so it is as bright as the text                                                                               | Always pair it with a border token: `border border-border-subtle-01`                                                                                                                                                                                                              |
| Colours in `<style>` blocks and `style=` attributes bypass the theme; v1 used black-on-white `rgba(0,0,0,…)`, invisible on Gray 100                                 | Replace with `var(--color-<token>)` or a class                                                                                                                                                                                                                                    |
| Svelte component CSS is unlayered and beats Tailwind's base layer; a route's `:global(body)` stays loaded after client-side navigation                              | No `:global(body)` font or colour; layout-only rules stay                                                                                                                                                                                                                         |
| `outline-none` / `outline-hidden` cancel the focus ring                                                                                                             | Drop them when restyling; buttons use Carbon's button focus                                                                                                                                                                                                                       |
| A field on `layer-01` (modal, table row) is the same colour as `field-01` and vanishes                                                                              | Use the 02 set: `field-02`, `field-hover-02`, `border-strong-02`                                                                                                                                                                                                                  |
| Tertiary button hover fills white                                                                                                                                   | Text and icon become `text-inverse` / `icon-inverse`                                                                                                                                                                                                                              |
| Status text in a status colour fails 4.5:1 on a hovered row                                                                                                         | Colour goes on the icon; the label is `text-primary`                                                                                                                                                                                                                              |
| Restyling a shared `ui/` component changes every screen that imports it                                                                                             | Smoke-check other importers; when the Carbon element differs (content switcher vs button group), make a new component                                                                                                                                                             |
| Tests query by role and name; a button that becomes a tab, or an enum shown as a label, breaks them                                                                 | Update the selector in the same commit, same intent                                                                                                                                                                                                                               |
| `svelte-sonner` removes every toast after 4 s                                                                                                                       | Error toasts pass `{ duration: Number.POSITIVE_INFINITY }`                                                                                                                                                                                                                        |
| A theme change re-sorts classes in files nobody touched: `prettier-plugin-tailwindcss` puts classes it does not know first                                          | Run `npx prettier --write .` and commit the re-sort on its own                                                                                                                                                                                                                    |
| The demo container runs as root and writes `.svelte-kit` into the worktree; `npm run check` then fails with EACCES                                                  | `chown` it back through `docker exec` — never `rm` it                                                                                                                                                                                                                             |
| `shadcn-svelte add` imports `tv` from `tailwind-variants` and bumps the package                                                                                     | Copy the files from `https://shadcn-svelte.com/registry/<name>.json` by hand; import `tv` from `$lib/utils`                                                                                                                                                                       |
| A Carbon type class without `text-` (`body-compact-01`) emits no CSS, and the token check misses it                                                                 | Always write `text-<type token>`                                                                                                                                                                                                                                                  |
| The unlayered `:focus-visible` rule in `app.css` beats `outline-offset-*` utilities                                                                                 | A ring outside the element needs its own unlayered rule in `app.css` (see the checkbox)                                                                                                                                                                                           |
| `carbon-icons-svelte` components are Svelte 4 (legacy mode)                                                                                                         | Don't force runes globally                                                                                                                                                                                                                                                        |
| Importing `carbon-icons-svelte` from the package index slows the dev server                                                                                         | Import `carbon-icons-svelte/lib/<Name>.svelte`                                                                                                                                                                                                                                    |
| A focused element that becomes `disabled` loses focus, which then falls out of a modal                                                                              | Use `aria-disabled` on buttons; move focus to the primary before disabling fields                                                                                                                                                                                                 |
| A field inside a dialog sits on `layer-01`, the same colour as `field-01`                                                                                           | Primitives carry `in-dialog:` 02-set classes; a new field primitive adds them too                                                                                                                                                                                                 |
| Tailwind's `group-data-[…]/x:` and other arbitrary variants fail the token check                                                                                    | Add a named `@custom-variant` in `app.css` (`in-dialog:`, `table-xl:`)                                                                                                                                                                                                            |
| A bits-ui `child` snippet spread over a caller's handlers replaces them                                                                                             | Merge with `mergeProps` from `bits-ui`                                                                                                                                                                                                                                            |
| `fetchSubTasks` (and other list fetches) merge every response into a global store                                                                                   | Keep the ids of the response you applied and list those, never the store's values                                                                                                                                                                                                 |
| bits-ui Select calls `scrollIntoView` and `hasPointerCapture`, which jsdom lacks                                                                                    | Stubbed in `vitest-setup.ts`; open with `keyDown` Enter, pick with `pointerUp` on the option (items select on `pointerup`)                                                                                                                                                        |
| bits-ui portals menus to `<body>`, so `in-dialog:` never reaches them                                                                                               | Style a menu for the 01 set; only the field takes `in-dialog:`                                                                                                                                                                                                                    |
| Content inside `ui/modal` sits in its `<form>`: a nested form's submit bubbles, and an untyped `<button>` submits it                                                | `ui/modal` saves only when the submitter is its primary; inner forms also `stopPropagation`                                                                                                                                                                                       |
| Carbon wraps a modal body and a ConditionBuilder popover in `<Layer>`; 01 surfaces vanish on layer-01                                                               | Give each layer/border class its `in-dialog:` 02 counterpart (the variant also covers `[data-slot="condition-popover"]`). The popover surface and the date picker's calendar are portalled outside the modal, so they stay 01; only items inside the builder popover switch to 02 |
| bits-ui wraps each Command item in a `display:contents` `[data-item-wrapper]`, so items are never siblings                                                          | Sibling and first-child selectors target the wrappers (`first-option:`, `after-active-option:`)                                                                                                                                                                                   |
| bits-ui Command marks the _highlighted_ option `aria-selected`                                                                                                      | Put the chosen state in `aria-checked`                                                                                                                                                                                                                                            |
| bits-ui returns focus to whatever was focused before a popover opened; after one popover opens the next, that is nothing                                            | `onCloseAutoFocus`: `preventDefault`, then focus the trigger (or open the next popover)                                                                                                                                                                                           |
| Deleting or rewriting a file with ESLint suppressions leaves unused ones, and `npm run lint` fails                                                                  | `npx eslint . --prune-suppressions` in the same commit; never hand-edit the file                                                                                                                                                                                                  |
| A `fixed` element inside `ui/dialog` content is placed against the dialog box (it is translated), not the viewport                                                  | Use it on purpose (the side panel stays in the picker); otherwise portal out. A `mask`, `filter` or `opacity` ancestor (e.g. the modal body's `modal-scroll-fade`) clips a `fixed` descendant: portal it to the dialog content (`getDialogContentElement`)                        |
| Carbon `border-subtle` at the page root is `-00`; a modal body and a side panel body are one Layer up                                                               | Pick the token for the surface: `-00` on `background`, `-01` on `layer-01`/in a modal                                                                                                                                                                                             |
| bits-ui Combobox writes the picked label into its input                                                                                                             | Clear the input after `tick()` when a pick is an action                                                                                                                                                                                                                           |
| bits-ui Popover content has no role (only the trigger gets `aria-haspopup="dialog"`)                                                                                | Add `role="dialog"` to `Popover.Content`                                                                                                                                                                                                                                          |
| Inside a Combobox, bits-ui sets `--bits-combobox-anchor-width`, not `--bits-select-anchor-width`                                                                    | Give the reused `Select.Content` `w-(--bits-combobox-anchor-width)`                                                                                                                                                                                                               |
| `8em` inside a 14 px text context is 112 px                                                                                                                         | Sizes meant in px use `rem`                                                                                                                                                                                                                                                       |
| A Tailwind breakpoint named `max` shadows the `max-*` variants: every `max-md:` class disappears from the build                                                     | Carbon's max breakpoint is `--breakpoint-cds-max` (`cds-max:`)                                                                                                                                                                                                                    |
| `ui/separator` and the `ui/field` parts `legend`, `separator`, `title`, `content`, `set`, `group`, `description` still use shadcn tokens (`bg-border` is undefined) | Run the token check on a `ui/` component before its first use, and restyle it in that change                                                                                                                                                                                      |

## Token check

Run it over the files you touched; it must print nothing outside the old viewer (`DESIGN.md`, Do's and
Don'ts). Put the files in `FILES`. The `-e` matters: one pattern starts with `-`. Use `[[:space:]]`, not
`\s` — inside a bracket in `git grep -E`, `\s` matches nothing.

```sh
FILES="src/routes/<screen> src/lib/<…> :!*llms.txt"   # *.svelte, *.ts, *.css only

# shadcn colour utilities (Carbon names like text-text-primary pass)
git grep -nE -e '(^|[[:space:]"'"'"'{:])(bg|text|border|ring|outline|fill|stroke|divide|placeholder)-(input|ring|foreground|primary|secondary|muted|accent|destructive|card|popover|sidebar|chart)\b' -- $FILES
git grep -nE -e 'border-border([[:space:]"'"'"'}/]|$)' -- $FILES

# Tailwind default palette
git grep -nE -e '(^|[[:space:]"'"'"'{:])(bg|text|border|ring|outline|fill|stroke|divide)-(white|black|slate|gray|zinc|neutral|stone|red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose)\b' -- $FILES

# Tailwind default type, weight, radius, shadow, width, outline removal
git grep -nE -e '(^|[[:space:]"'"'"'{:])(text-(xs|sm|base|lg|[2-9]?xl)|font-(thin|extralight|light|normal|medium|semibold|bold|extrabold|black)|rounded(-(xs|sm|md|lg|xl|[2-4]xl))?|shadow(-(2xs|xs|sm|md|lg|xl|2xl))?|max-w-(xs|sm|md|lg|xl|[2-7]xl)|outline-(none|hidden))([[:space:]"'"'"'}]|$)' -- $FILES

# Tailwind's own breakpoint prefixes (Carbon's md: lg: xlg: pass; tv size keys like `sm: "…"` pass)
git grep -nE -e '(^|[[:space:]"'"'"'{])(sm|xl|2xl):[a-z-]' -- $FILES

# Colour literals, fonts and old variables in <style> blocks and style= attributes
git grep -nE -e '#[0-9a-fA-F]{3,8}\b|rgba?\(|hsla?\(|font-family|var\(--(background|foreground|popover|muted|border|input|ring|primary|secondary|accent|destructive|card|sidebar|chart)|var\(--color-(foreground|popover|muted|border|input|ring|primary|secondary|accent|destructive|card|sidebar|chart)(-[a-z-]*foreground)?[),]' -- $FILES ':!src/app.css'

# dark: variants, and arbitrary values (data-[state=open]: and has-[>svg]: pass)
git grep -nE -e 'dark:' -e '-\[[^]]*\]([^:]|$)' -- $FILES

# Named CSS colours in <style> blocks and style= attributes
git grep -nE -e '(color|background|border|outline|fill|stroke|box-shadow)[a-z-]*[[:space:]]*:[^;]*\b(white|black|gray|grey|silver|red|green|blue|yellow|orange|purple|darkolivegreen|lightgray|lightgrey|darkgray|darkgrey|whitesmoke|gainsboro)\b' -- $FILES
```
